## Q1 Null and what is random
Observed. The key is random and defines a random rejection region (p.4): "The service" / "provider achieves this by sharing a watermark key (generated from a distribution that is" / "coupled with ρ) with the detector, with the goal of controlling both the Type I error (an" / "independent output is falsely detected as from ρ) and the Type II error (an output from ρ" / "fails to be detected). This random key together with the detection rule constitute a (random)" / "rejection region."

Observed. Problem 2.1 (p.4): "an ϵ-distorted watermarking scheme of ρ is a probability measure P (a joint" / "probability of the output X and the rejection region R) over the sample space Ω ⊗ 2Ω". Hypotheses (p.5): "H0 : X is sampled independently from R," / "versus H1 : (X, R) is sampled from the joint distribution P."

Observed. Type I error definition (p.5): "The Type I error of P, defined as α(P) := supπ∈∆(Ω) PY ∼π,(X,R)∼P (Y ∈ R), is the maximum probability that an independent sample Y is falsely rejected."

Observed. Cryptographic reading of the key (p.5, Remark 2.3): "the service provider could hash a secret key sk, and use" / "pseudo-random functions F1 , F2 to generate (X, R) = (F1 (sk), F2 (sk)). Now it suffices" / "to send the secret key to the detector, who can then reproduce the reject region using the" / "pseudo-random function F2 ." and "By introducing the coupled and random rejection region, we abstract away the minutiae" / "of cryptographical implementations, therefore allowing us to focus solely on the statistical" / "trade-offs."

Observed. In the proofs the Type I error is a probability over the random rejection region (p.20): "In the bound of Type I error, choosing π = δy yields" ... "= PR∼η (y ∈ R)". For the model-agnostic construction (p.27): "Notice that the marginal distribution of reject region" (η* uniform over sets A with |A| = αn) "already guarantees Type I error ≤ α."

Observed. Table 1 (p.15): "we show the (average) minimum number of tokens" / "needed to detect the watermark under the constraint that type I error is less than α = 0.02."

Reader's inference. Here the "key" is the random rejection region R itself. Under H0 the text Y is independent of R and the Type I error is sup over text laws π of P_{Y∼π, R∼η}(Y ∈ R): worst case over the text, but averaged over R (the key). It is marginal over the key. Indeed, for the minimax model-agnostic scheme the rejection region is a fixed set A of size αn once the key is realised; conditional on that A, a text law concentrated on an element of A would have false-positive probability 1, while the average over A ∼ η* gives exactly α. There is no i.i.d.-uniform pivotal statistic in this framework; the null is "X is sampled independently from R".

## Reader's inference
1. Q1: marginal over the key. The Type I error α(P) = sup_π P_{Y∼π,(X,R)∼P}(Y ∈ R) takes the probability over the random rejection region R (equivalently the key) and the worst case only over the text law; the proof on p.20 reduces it to P_{R∼η}(y ∈ R).
2. Q2: Remark 3.6 (reuse of "the same key" for many outputs) is the only key-reuse statement; no per-key false-positive analysis.
3. Q3: no empirical false-positive rate is reported; the experiment fixes α = 0.02 and reports tokens-to-detection.
4. Reader's inference, not in the text: in the minimax model-agnostic scheme the rejection region is a fixed set A with |A| = αn once R is realised, so the key-conditional false-positive rate for an arbitrary text law is not controlled (it can be 1 for a point mass inside A), while the average over A is α. This makes the paper a clean theoretical example of a marginal-only guarantee.
5. Decisive quotation (p.5): "The Type I error of P, defined as α(P) := supπ∈∆(Ω) PY ∼π,(X,R)∼P (Y ∈ R), is the maximum probability that an independent sample Y is falsely rejected."
