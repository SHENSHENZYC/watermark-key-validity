## Q1 Null and what is random
Observed. Hash form (p.7, eq. (5)): "ζt = A(w1:(t−1) , Key)," and "where Key denotes a secret key that will be passed to the verifier. The (deterministic) hash function" / "A maps any token sequence and a key to a pseudorandom number that will be used to generate the" / "next token."

Observed. Working Hypothesis 2.1 (p.7): "Working Hypothesis 2.1 (Soundness of pseudorandomness). In the watermarked LLM, the" / "pseudorandom variables ζ1:n constructed above are i.i.d. copies of a random variable. Furthermore," / "ζt is (statistically) independent of w1:(t−1) ." Justification (p.7): "The pseudorandom number" / "is very sensitive to the key, making it computationally indistinguishable from its truly random" / "counterpart without knowledge of the key." Footnote 3 (p.3): "Strictly speaking, ζt has no randomness. However, modern cryptographic theories ensure that ζt behaves very" / "much like a random variable." And (p.8): "Hereafter, we regard ζ as a random variable, which allows us to formally define the unbiasedness" / "of a watermark."

Observed. Working Hypothesis 2.2 (p.8): "Working Hypothesis 2.2 (Intrinsic nature of human randomness). Let w1:n be a sequence of" / "tokens generated by a human who has no knowledge of the secret key. Then, the human-generated" / "token wt and ζt are (statistically) independent conditional on (w1:(t−1) , ζ1:(t−1) ), for all 1 ≤ t ≤ n." Remark 2.1 (p.8): "In particular, Working Hypothesis 2.1" / "remains valid for human-generated text, due to the construction of the hash function A."

Observed. Pivot and reduced testing problem (p.9): "we seek a pivotal statistic Yt = Y (wt , ζt ) such that its distribution" / "is the same for any NTP distribution Pt under the null." Eq. (9) (p.9): "H0 : Yt ∼ µ0 i.i.d. for 1 ≤ t ≤ n". For Gumbel-max (p.14): "This is because Ut,wt follows the standard uniform distribution under H0 while" / "being stochastically larger under H1 , as ensured by Working Hypotheses 2.1 and 2.2."

Observed. Type I error statement (p.10): "The threshold γn,α is" / "chosen to ensure significance level at α: PH0 (Th (Y1:n ) = 1) = α." CLT-based threshold (p.10): "an estimator of γn,α when the text is sufficiently long is" γ̂n,α = n·E0 h(Y) + Φ^{-1}(1−α)·sqrt(n·Var0(h(Y))) (formula typeset on p.10; also p.64). Proof-level statement (p.35): "Under the null hypothesis, Yt are i.i.d. copies of µ0 ."

Observed. Footnote 8 (p.8) on prior work: "In particular, they assumed that A(w1:n , Key) is i.i.d. for any w1:n ."

Reader's inference. The randomness in the null is the pseudorandom sequence ζ1:n, modelled as truly i.i.d. ("we regard ζ as a random variable") because of the key's cryptographic role; human text is treated as independent of ζ given the past. The guarantee PH0(Th = 1) = α is thus stated under the idealised law of ζ, i.e. marginal over the key; there is no conditional-on-a-fixed-key statement, and the pivotal statistic is declared i.i.d. uniform (Gumbel-max) under H0 by Working Hypotheses 2.1-2.2.

## Q3 Empirical FPR procedure
Observed. Synthetic (p.26): "Our initial investigation is on Type I error control for finite token sequences, recognizing that the" / "guarantees for Type I error control follow from the central limit theorem and hold asymptotically" / "when the sequence length T → ∞. For a given text length T , we generate 5, 000 samples of" / "unwatermarked word tokens sequences. We uniformly sample each unwatermarked token from the" / "vocabulary W in our experiments." Result (p.26): "the Type I errors" / "generally align with the nominal level of 0.05, fluctuating between 0.04 and 0.06." Exception (p.26): "The only" / "exception is the score function hind,δ (Y gum ), achieving close to the nominal 0.05 level only for token" / "sequences over 300 in length, where asymptotic effects emerge."

Observed. Simulation hash (p.64): "We employ a context window of size m = 5, allowing the" / "randomness variable ζt = A(s(t−m):(t−1) , Key) to depend on the previous m tokens." and "This seed is then used with a pseudo-random number generator, specifically" / "the PCG-64 generator [46], which is the default option in Python’s NumPy package [27]." Critical value by simulation for h⋆dif (p.64): "This procedure is replicated 500 times, using the empirical" / "1 − α quantile as an initial estimate. To enhance the precision of this estimate, we repeat the process" / "10 times and average these ten initial estimates to establish the final critical value."

Observed. Real data (p.27): "we evaluate Type I errors on the unwatermarked texts directly from large token generation models" and "both the average Type I error" / "(leftmost column of Figure 7) and Type II error (rightmost column of Figure 7) curves are computed" / "based on 500 repeated experiments." Result (pp. 27-28): "First, in most scenarios, all the detection methods maintain Type I errors within 0.04 to 0.06," / "aligning well with the expected 0.05 level, particularly in texts over 100 tokens long". Hash in real data (p.65): "The hashing function A is the Skip function from [36] with the window size m = 4." Models: OPT-1.3B and Sheared-LLaMA-2.7B, temperature 0.1 (p.65); Figure 11 (p.67): "Each curve is averaged over 500 samples from the C4 dataset."

Observed. Number of keys: not found (searched: key, Key, seed, keys); the key is referred to only as "Key".

Reader's inference. Empirical FPR = fraction of rejections over null texts (5,000 synthetic sequences; 500 real unwatermarked texts), compared with the nominal 0.05; the only discrepancy noted is finite-sample CLT inaccuracy for the indicator score; no key-to-key variation is examined.

Observed. For hash collisions the paper points to heuristics of [22] and to full-history hashing (p.64): "To mitigate this, [22] proposed heuristic methods to address such" / "repetitions (see their Part C in Section III). ## Reader's inference
1. Q1: the Type I guarantee is marginal over the key. Working Hypothesis 2.1 declares ζ1:n i.i.d. "copies of a random variable" by cryptographic indistinguishability; the paper explicitly says "we regard ζ as a random variable" (p.8). Nothing is conditioned on a realised key.
2. Q2: no discussion of per-key dispersion; the nearest content is Remark D.1 (within-text hash collisions), declared out of scope.
3. Q3: empirical FPR is a text-averaged rate under (apparently) one key: 5,000 synthetic null sequences, 500 real unwatermarked texts; it matches 0.05 within 0.04-0.06.
4. Decisive quotation: p.7, "pseudorandom variables ζ1:n constructed above are i.i.d. copies of a random variable."
