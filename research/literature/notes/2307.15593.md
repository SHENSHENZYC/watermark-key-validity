## Q1 What is random; conditional or marginal

Observed.

- The key is drawn at random and shared (p.5, protocol step 0): "0. The LM provider shares a random watermark key sequence ξ ∈ Ξ∗ with the detector;"
- The null hypothesis is independence of text and key (p.5, step 4): the detector decides "by computing a p-value pb = detect(Ye , ξ) with respect to the null hypothesis that Ye is independent of ξ (i.e., not watermarked)."
- The validity statement, the only one in the paper (p.6): "The output pb of detect is a proper non-asymptotic p-value:" followed by "if Ye is not watermarked, then each (Ye , ξ (t) ) constitutes an independent, identically distributed copy of (Ye , ξ) and therefore by symmetry pb is uniformly distributed over {1/(T + 1), 2/(T + 1), . . . , 1}" and "for any (non-atomic) test statistic."
- The resampled keys come from the key distribution (Algorithm 2, p.7): "Params: test statistic ϕ; watermark key sequence distribution ν ∈ ∆(Ξn ); resample size T" and line 2 "ξ (t) ∼ ν".
- The only assumption on the key (p.9, preamble to Lemma 2.2): "we make no assumption on the distribution of ξ except that it is independent of unwatermarked text by definition".
- Validity is asserted independently of the statistic (p.13): "To reiterate, the output of detect is a valid p-value irrespective of the test statistic we use." and footnote 7 (p.13): "Also, irrespective of the lemmas, the p-values from detect are still valid by construction."
- The power bounds condition on the text, never on the key. Lemma 2.4 (p.11): "Let ξ, ξ ′ ∼ Unif(Ξn ) with Y = generate(ξ; n, p, Γ) and Ye = Y . Then almost surely" "P(ϕ(Ye , ξ ′ ) ≤ ϕ(Ye , ξ) | Ye ) ≤ 2n exp(−kC02 α(Ye )2 /2)." Lemmas 2.5, 2.6, 2.8, B.2 and C.2 (pp.12–13, 15, 32, 37) condition on the text in the same way, written "| Y, Ye )", "| Ye , Y )" or "| Ye )".
- Distortion-freeness is defined as a marginal-over-key property (p.2): "our watermarks are distortion-free in the sense that—marginalizing over the watermark key sequence—each call to generate is equal in distribution to a sample from the original language model".

Reader's inference. The random objects in the validity statement are the deployed key ξ and the T resampled keys ξ^(t), all i.i.d. from ν; the published text Ỹ enters only through the independence assumption and can be treated as fixed. The symmetry argument gives exchangeability of (ϕ(Ỹ,ξ), ϕ(Ỹ,ξ^(1)), …, ϕ(Ỹ,ξ^(T))) conditional on Ỹ, so the p-value is exactly uniform conditional on the text and averaged over the key. The guarantee is therefore marginal in the key and conditional in the text. No statement is made about the error rate for one fixed key averaged over texts, and no quantity corresponding to a key-conditional false-positive rate is defined or bounded.

## Q2 Fixed key / per-key / conditional vs marginal

Observed.

- The phrase "conditionally valid" occurs once (p.21, Alpaca case study): "We then compute conditionally valid p-values for each response using the original version of detect with T = 500."
- Experiments 1–6 replace key resampling by a null-text reference distribution (p.16): "to save computation we simply sample T prompts and compute the test statistic once for each ground-truth length m completion; we then use the empirical distribution of these test statistics as the reference distribution within detect," continuing "which gives a proper p-value with respect to the null hypothesis that the text is an original completion from the dataset."
- The same construction is called approximate in footnote 14 (p.26): "In principle, running detect requires recomputing the test statistic for each resampled watermark key in order to obtain an exact p-value." and "we can avoid this recomputation and still obtain approximate p-values with respect to some reference distribution of unwatermarked text, in which case we need only compute the single test statistic once (using the original watermark key) during watermark detection (Algorithm 5)."
- Pseudocode (p.39): "Algorithm 5: Watermarked text detection with fixed reference distribution". The reference distribution (Algorithm 6, p.40) draws a fresh key for every reference text: "ξ (t) ∼ ν" then "ϕt ← ϕ(Y−m: , ξ (t) )".
- Correlation induced by sharing one key across queries is dismissed empirically (p.8): "while in principle these n texts will correlate with each other due to sharing elements of the watermark key sequence, in practice we find the effects of these correlations are not noticeable."
- Footnote 7 (p.13), on the single shared permutation used in practice: "In principle, with a single random permutation the permuted token indices of both watermarked and nonwatermarked text are no longer conditionally independent of each other, and so the results of Lemmas 2.4, 2.5 and 2.6 no longer apply."
- "deployed" occurs once and refers to models, not keys (p.27): "We conclude with some salient recommendations for practitioners aiming to watermark their deployed language models."
- Variation of error rates across keys, a fixed or deployed key, per-key calibration, key screening: not found (searched: key, fixed, conditional, marginal, derandom, aggregat, deployed, screening, false positive, Type I, per-key, calibrat, same key, single key, given key).

Reader's inference. Algorithm 5/6 is a null-text calibration, but because Algorithm 6 redraws the key for each reference text, the reference distribution is the null distribution of the statistic marginal over (text, key), not the null distribution under the deployed key. The p-value that results compares one (text, deployed key) pair against that marginal reference; it does not isolate the deployed key's own null distribution, so the histograms of Figures 15–20 cannot reveal per-key dispersion. The paper's own labels for this construction conflict: "proper" on p.16 versus "approximate" on p.26.

## Q3 Empirical FPR procedure

Observed.

- Generation (p.16): "We run experiments using generate rather than shift-generate, mainly for the sake of reproducibility; recall however that this choice has no impact on the p-values we report."
- Sample sizes and resamples (p.16): "we report median p-values of watermarked text over 500 samples." and "we use detect (with T = 5000) to report p-values for all watermarks;" with footnote 11: "This setting of T means we never report p-values less than 1/5000 (i.e., 0.0002) in any of our experiments."
- Footnote 10 (p.16) ties the median p-value to the Type I level: "The median p-value corresponds to the significance level (i.e., Type I error rate) at which the power of our watermark detector is at least 0.5."
- Null check is visual only (p.16): "we also plot the full distributions of p-values for nonwatermarked generations (i.e., regular samples from the language models) to verify they are indeed roughly uniform over the interval [0, 1]." and (p.39): "As a sanity check, we include histograms of the p-values we compute for nonwatermarked text for each method to verify that they are roughly uniformly distributed on the interval [0, 1]" with the setting "setting m = 50 and sampling prompts from the news-like subset of the C4 dataset, as in Experiment 1" and the caveat "In the cases of KGW-1.0 and KGW-2.0, the distribution is not quite uniform due to the discrete nature of their test statistics." Figures 15–20 (pp.40–43) are these histograms for ITS, ITS-edit, EXP, EXP-edit, KGW-1.0, KGW-2.0 on OPT-1.3B and LLaMA-7B.
- A numeric empirical false-positive rate compared with a nominal level: not found (searched: false positive, Type I, nominal, uniform).
- Key length (p.17): "fixing the watermark key length n = 256 for each of our watermarks". Number of distinct keys used in Experiments 1–6: not stated. The only multi-seed statement concerns the Alpaca sample sheets (p.50): "we generate the samples using five different random seeds".

Reader's inference. The null behaviour is assessed with histograms, apparently for a single key sequence per run (the paper never says how many keys), against a reference built with a fresh key per reference text; no per-key or multi-key false-positive table exists, and no nominal level is tested numerically.

## Q4 Remedies and guarantees

Observed.

- Remedy 1, exact resampling p-value (Algorithm 2, p.7): the uniformity claim quoted under Q1, marginal over the key.
- Remedy 2, fixed reference distribution from null texts (Algorithm 5 p.39, Algorithm 6 p.40). Claimed guarantee on p.16: "a proper p-value with respect to the null hypothesis that the text is an original completion from the dataset." Claimed status on p.26: "approximate p-values with respect to some reference distribution of unwatermarked text".
- Multi-query distortion control by key length (p.8): "for T queries and a maximum generation length of m tokens per query, we will achieve negligible, i.e., o(1) distortion, so long as n = ω(mT 2 )."
- Aggregation over keys, e-values, derandomisation, Dual Watermarking: not found (searched: aggregat, derandom, e-value, dual).

Reader's inference. The paper offers the two ingredients that a key-conditional analysis would need (a key-resampling null and a null-text reference) but never combines them for a fixed key, and never states which null (key-marginal or text-marginal) the practitioner's p-value controls.

## Q5 Limitations and future work

Observed.

- (p.26) "the main inherent limitation of watermarking is that the detector must trust the LM provider to faithfully apply the watermark when generating text."
- (p.26) "the computational complexity of our watermark detection algorithms grows linearly with the length of the watermark key sequence."
- (p.26) "Whether this apparent tension between detection complexity, robustness and (approximate) distortion-freeness is due to fundamental trade-offs is an interesting open question."

- Contrast with classifiers (p.5): classifiers "do not provide a priori (distribution-free) guarantees on the significance level of detection (i.e., Type I errors)."

## Reader's inference

1. The validity theorem is a key-marginal, text-conditional statement: uniformity of the p-value is proved by exchangeability of the deployed key with T resampled keys for a fixed text. It says nothing about the false-positive rate of one deployed key over a population of texts, which is the quantity the research question asks about.
2. The paper's own experiments abandon key resampling for a text reference distribution (Algorithm 5/6), which is a null-text calibration, but the reference statistics are computed with fresh keys, so the calibration is to the (text, key)-marginal null, not to the deployed key. This is the closest the paper comes to the research question and it does not answer it.
3. Dispersion of the false-positive rate across keys, per-key calibration and key screening are absent. The paper's mild remarks about key-sharing correlations (p.8) and the single shared permutation (p.13, footnote 7) are the only places where the fixed nature of the deployed randomness is acknowledged, and in both the authors rely on empirical reassurance rather than a guarantee.
4. The most decisive quotation for the gate is the p.6 validity sentence, because it makes explicit that the probability is taken over the key draw ("each (Ye , ξ (t) ) constitutes an independent, identically distributed copy of (Ye , ξ)").
