## Q3 Adequacy tests and results

Observed (the main test, Section 3.1, pp.5–6): "In this section, we conduct a likelihood ratio test on real-world datasets to examine the hypothesis that realworld game outcomes are generated by the BT model." (p.5) The BT logistic model on a random half of the games (T_test) is augmented with two extra parameters α ∈ R² on a two-dimensional per-game feature g_t built from the other half (T_train); "Therefore, we can test the BT model by testing the null hypothesis H0 : α = 0." (p.6) The statistic Λ is twice the difference of minimised negative log-likelihoods, and "under the null hypothesis that the real-world dataset is generated by Bradley-Terry model, Λ is asymptotically distributed as a chi-square distribution with two degrees of freedom." (p.6) A high-dimensional correction is applied: "We applied the correction suggested by Sur et al. (2019) by computing the p-value conservatively with 1.25χ22 ." (p.6) The default feature is g_t = [θ_train[i_t], θ_train[j_t]], the ridge-regularised (λ = 10.0) BT scores fitted on the training half (p.6, p.15).

Observed (arena-specific feature, p.5 footnote 2 and p.15): "The likelihood-ratio test is performed for the LLM arena dataset using a different method of augmenting the features." (p.5); "For llm arena, Hearthstone, AlphaStar and Blotto, the aforementioned feature failed to reject the null." (p.15); "Since those datasets are relatively dense, we designed a different feature inspired by (Bertrand et al., 2023)." (p.15) — a rank-2 skew feature g_t = [u[i_t]v[j_t], u[j_t]v[i_t]] learned on the training half by gradient descent with early stopping; "This method does not apply to other datasets as it requires a dense dataset for the learning of u and v." (p.15)

Observed (results, Table 1, p.5; column "BT Model Test" is Λ): Renju 150.0 (p < 10^-10); Chess 2020.1 (p < 10^-10); Tennis 37.3 (p < 10^-4); Scrabble 142.2 (p < 10^-10); StarCraft 775.8 (p < 10^-10); Go 193411.2 (p < 10^-10); LLM Arena 73.1 (footnote 2 method), p-value 1 × 10^-3; Hearthstone 49.0 (p < 10^-4). Conclusion drawn: "It can be seen that we can reject the null hypothesis, namely realizability of the Bradley-Terry model, with extremely high confidence, for all eight datasets." (p.6)

Observed (martingale variant, Appendix B.3, pp.15–16): to drop the independence assumption between halves (a concern under adaptive matchmaking), g_t is replaced by the online Elo ratings [θ_t[i_t], θ_t[j_t]] computed from the past t−1 games with learning rate η; Λ is again referred to χ²₂. Table 3 (p.16): LLM Arena LR statistic 872.28 (η = 0.01), p < 10^-10, and 819.05 (η = 0.08), p < 10^-10; Renju 3.66 (p = 0.23) and StarCraft 5.19 (p = 0.12) fail to reject at η = 0.01 but reject at η = 0.08 (226.92 and 261.08). "We find that by using two learning rates (η = 0.01 and 0.08), we can reject the null hypothesis that BT is realizable with extremely high confidence without assuming independence." (p.16)

Observed (non-stationarity diagnostics, Appendix C, pp.16–17): the correlation between θ_train[i_t] and θ_train[j_t] over test games ("Matchmaking Test", Table 4, p.16) is 0.37 for LLM Arena (p < 10^-10), 0.40 Chess, 0.57 Scrabble, −0.07 Hearthstone; "In other words, in many real datasets, stronger (higherrated) players are matched with stronger opponents." (p.16) A permutation/bootstrap test on chess (100 permutations of game order) finds the time-ordered Elo vector "is a significant outlier and is not identically distributed with θbootstrap with high probability (p = 0.01 via the permutation test)." (p.17)

Observed (predictive comparison, Table 2, p.7; average cross-entropy, lower is better): LLM Arena — Elo 0.6607, Glicko 0.6602, TrueSkill 0.6611, Elo2k 0.6611, Pairwise 0.6619 (Chess and Go have no Pairwise entry). "Among these dense datasets, LLM is special, since the Elo2k baseline and the Elo baseline are so close, that even the dataset is dense, Elo2k does not show any benefit." (p.20)

Observed (overall conclusion): "In this paper, we find that real-world game data are non-BT and non-stationary." (p.11)

Not found: any goodness-of-fit test against the saturated pairwise model, deviance or Pearson residual analysis, tie-model comparison, cyclic-triad or stochastic-transitivity test on real data, or homogeneity tests across prompt category, language, session or voter (searched: goodness, lack of fit, saturated, triad, cycl, heterogene, homogene, categor, language, session, voter, prompt). Observed: the authors say explicitly that transitivity testing is hard on sparse data: "Although rejecting even weak notions of transitivity would automatically reject the BT model, doing so with hypothesis testing can be difficult for most real-world datasets where the majority of player pairs never played with each other." (p.3)

Reader's inference: the test is a 2-degree-of-freedom directional score/LR test for omitted covariates (train-set ratings, or a rank-2 intransitive component), not an omnibus lack-of-fit test; for the arena it rejects at p ≈ 10^-3 with the rank-2 feature and at p < 10^-10 with the martingale (online-Elo) feature, but the latter also confounds non-stationarity with non-BT structure, which the authors treat jointly ("non-BT and non-stationary"). The paper also records that the default feature did not reject BT on the arena data.

## Q4 Uncertainty and propagation

Observed: the only interval computation is in the synthetic Example 1 (Appendix G.2, p.22): "we construct confidence interval for each player’s Elo score by bootstrapping (following the procedure in chatbot arena)" (p.22), 100 bootstrap resamples of T = 10000 games, 5%–95% quantiles; the resulting intervals [4.86, 5.33], [0.72, 1.17], [4.18, 4.68], [−0.07, 0.31], [0.00, 0.00] are disjoint for players 1–4, and "From these confidence intervals, we can confidently say the Elo scores give the ranking 1 ≻ 3 ≻ 2 ≻ 4, which is inconsistent for players {1, 2, 3, 4}." (p.22)

Observed: no confidence intervals, standard errors or rank uncertainty are reported for any real dataset, including the arena; the matchmaking and non-stationarity findings are reported as separate tests, not folded into rating uncertainty. "However, we caution that Elo should not be blindly trusted, as it can fail to produce consistent total orderings under arbitrary matchmaking, even in transitive datasets." (p.2)

Not found: propagation of misspecification into rank uncertainty (searched: confidence interval, bootstrap, uncertaint). Reader's inference: the Example 1 result is the paper's closest statement to the gate question — it shows, on synthetic SST data with non-uniform matchmaking, that arena-style bootstrap intervals can be tight around a wrong ordering — but it is not demonstrated on arena votes.

## Reader's inference

Reader's inference: this is the one paper of the four that actually runs a formal test of BT on public Chatbot Arena votes (129 models, ~1.49M battles) and rejects it (Λ = 73.1, p = 1 × 10^-3 with a rank-2 intransitivity feature; Λ ≈ 820–870, p < 10^-10 with the online-Elo martingale feature), while also noting that the default train-set-rating feature did not reject on the arena. The test is a low-dimensional augmented-logistic LR test, not a saturated-model deviance, tie-model, triad-count or heterogeneity test; it does not report how arena ties were handled; and it does not propagate the detected misspecification or non-stationarity into any rank uncertainty for the arena leaderboard — the only CI exercise is synthetic and shows arena-style bootstrap CIs can be confidently wrong under non-uniform matchmaking. For the gate: it establishes that BT is rejected on arena votes but leaves open which departures are present and what they do to rank uncertainty.
