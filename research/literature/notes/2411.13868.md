## Q1 Null and what is random
Observed. Protocol (p.6): "The model provider embeds a statistical watermark" / "into the generated text using a secret key Key, which is shared with the verifier (e.g., a teacher), but" / "not with the user." Hash (p.6): "Specifically, at each step t, the model computes a pseudorandom variable ζt = A(w(t−m):(t−1) , Key)," / "where A is a cryptographic hash function, Key is the watermarking key, and m is the context window" / "size."

Observed. Modelling assumption (p.7): "For theoretical analysis, we model ζt as i.i.d. samples from a reference distribution" / "π, reflecting the cryptographic properties of A [5, 66, 73, 80]."

Observed. Null (p.7): "In this way, under the null hypothesis" / "H0 , where the text is entirely human-written, the statistics Yt are i.i.d. samples from a known" / "reference distribution µ0 ." Eq. (1) (p.7): "H0 : Yt ∼ µ0 i.i.d. for 1 ≤ t ≤ n v.s. H1 : Yt | Pt ∼ µ1,Pt for 1 ≤ t ≤ n." Uniformity (p.7): "The method works because, without a watermark," / "the Ut,wt ’s are i.i.d. U (0, 1), so Yt ∼ µ0 = U (0, 1)." Mixture formulation, eq. (4) (p.8): "H0 : Yt ∼ µ0 , i.i.d. ∀1 ≤ t ≤ n v.s. H1mix : Yt | Pt ∼ (1 − εn )µ0 + εn µ1,Pt , ∀1 ≤ t ≤ n."

Observed. Formal assumption (p.11): "(a) Perfect pseudorandomness: ζ1:n are i.i.d. and ζt ⊥ Ft−1 ." with commentary: "This treatment—viewing pseudorandom as" / "truly random—is standard in the watermarking literature, whether explicitly stated [73, 80, 59, 47]" / "or assumed implicitly [43, 44, 22]."

Observed. Type I error statements. Remark 3.1 (p.10): "Given the setup in (4), where Y1:n are i.i.d. samples from µ0 , the Type I error can be" / "controlled by carefully choosing this critical value. Notably, this control is independent of any human" / "edits." Definition 4.1 (p.14): "Let γn,α be the critical value that ensures a Type I error of α for the problem" / "(4), that is, P0 (S(Y1:n ) ≥ γn,α ) = α for all n ≥ 1." Proof of Theorem 4.3 (p.46): "We start by analyzing the Type I error. Under H0 , Yt ’s are i.i.d. U (0, 1) so" / "that Fn (r) is the empirical CDF of n i.i.d. U (0, 1) random variables." Theorem 4.3 (p.13): "the sum of Type I and Type II errors tends to 0 as n → ∞."

Observed. Why edits break the hash link (p.8): "Because any cryptographic hash" / "function A is highly sensitive to input changes, even a minor modification results in a statistically" / "independent output."

Reader's inference. What is random under H0 is the pseudorandom sequence ζ (Assumption 4.1(a): i.i.d., independent of the past), treated as truly random; the human text is conditioned on through the filtration. The guarantee P0(S ≥ γn,α) = α is a statement under this idealised law, i.e. marginal over the key; no fixed-key (conditional) statement appears.

## Q3 Empirical FPR procedure
Observed. Simulations use true randomness (p.15): "We use a vocabulary of size |W| and model the pseudorandom variables ζt,w as true i.i.d. samples" / "from U (0, 1). We will explore the practical setting where ζt is computed via a hash function later." and (p.57): "Again, we replace pseudorandomness with true" / "randomness for illustration purposes."

Observed. LLM experiments (p.19): "we set the significance level at α = 0.01 by tuning the critical values, either using central limit" / "theorem predictions or Monte Carlo simulations. We assess the actual Type I errors using" / "unwatermarked texts and Type II errors using watermarked texts." (p.20): "We begin by examining Type I error control, using 5000 unwatermarked" / "texts sampled from the C4 dataset as human-written data and evaluating Type I error at the" / "significance level α = 0.01." Result (p.20): "across all detection methods, empirical Type I errors remain" / "well-controlled within the interval [0.006, 0.014]. This suggests that the pseudorandom variables" / "effectively mimic the behavior of true random variables, enabling their empirical performance to" / "closely align with theoretical expectations."

Observed. Hash in LLM experiments (p.57): "We employ a context window of size m = 5, allowing the randomness variable ζt = A(s(t−m):(t−1) , Key)" / "to depend on the previous m tokens. We utilize the hash function A, as used in [80], for generating" / "this randomness."

Observed. Critical values (p.58): "Critical values are used to control the Type I error. For" / "sum-based detection rules, we estimate the critical value by" the CLT formula (typeset on p.58), and for Tr-GoF: "To determine the" / "critical value for HC and Tr-GoF, we resort to simulation. For a given text length n and s ∈ [−1, 2]," / "we generate n i.i.d. copies of Yt from U (0, 1) and calculate the corresponding statistic log(nSn+ (s))." / "This procedure is replicated 104 times, using the empirical 1 − α quantile of these 104 samples as" / "an initial estimate. To enhance the precision of this estimate, we repeat the process 10 times and" / "average these 10 initial estimates to establish the final critical value." (Observed: "104" is pdftotext's rendering of 10^4.)

Observed. Number of keys: not found (searched: key, Key, seed, keys). Explanation of discrepancies: none needed by the authors; the observed band [0.006, 0.014] is attributed to pseudorandomness mimicking true randomness (p.20).

Reader's inference. The empirical FPR is a text-averaged rate over 5000 null C4 texts, apparently under one key, compared against 0.01; the critical values are computed from the idealised i.i.d.-uniform null, not from null texts or from the deployed key.
