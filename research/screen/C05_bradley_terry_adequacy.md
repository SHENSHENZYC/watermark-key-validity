# C05 — Bradley–Terry adequacy on public arena preference data (search-level screen, 2026-10-08)

Conventions. "Observed" sentences report what a search result or page said; anything obtained through the fetch tool is a paraphrase and is marked "via fetch tool". "Inference" and "Proposal" sentences are mine. Every "nothing found" statement is search-level; absence is not proof of novelty.

## Candidate (one sentence)
Do crowd pairwise preferences in the public arena releases satisfy the Bradley–Terry model (stochastic transitivity, homogeneity across voters, sessions and prompt categories, the tie model), and how much do the violations move the rankings and their stated uncertainty relative to the Bradley–Terry/Elo pipeline the arenas use?

## Residual gap
Type: adequacy check. Observed: I found no study that runs classical specification tests for paired-comparison models on the public arena releases — likelihood-ratio tests against a saturated or nonparametric pairwise model, Rao–Kupper versus Davidson versus the half-win tie treatment, triad-level stochastic-transitivity tests against the BT-implied baseline, category-, language- and session-specific fits with homogeneity tests — and then propagates each violation into the rank spread as Arena-Rank computes it. Search-level; absence is not proof of novelty; the queries that returned nothing on this combination were the WebSearch query on transitivity/goodness-of-fit/misspecification and the arXiv web search on `Bradley-Terry misspecification`; the arXiv API tie-model query did not complete. Inference: the tie model is the least occupied axis (the extended-models post is silent on ties; arenakit may cover Rao–Kupper), and the session and judge-hash fields make a voter-homogeneity test possible that at least one 2026 paper described as blocked. Proposal: a pre-registered specification battery on the 55k, 100k and 140k releases (Apache-2.0 and CC-BY-4.0 prompts), reporting for each test the change in point ranks, in Arena-Rank's closed-form intervals and in rank spread, with the Arena-Rank package as the comparator pipeline.

## Novelty score
3 / 5. Justification: the heterogeneity, fragility and uncertainty-reporting angles are heavily occupied, and 2502.10985 has already reported that paired-comparison data departs from Bradley–Terry; but a formal specification-test battery including the tie model and its effect on the arenas' stated rank uncertainty was not found at search level. The arenakit package (unverified) is the nearest competitor and must be checked before locking.
