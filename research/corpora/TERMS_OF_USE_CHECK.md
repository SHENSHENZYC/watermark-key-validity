# Terms-of-use check — null corpora and tokenizers for Stage 4 (2026-10-09)

Checked **before any download** (guide rule A4.6; frozen-data-provenance skill). Every clause below is quoted verbatim from the primary page or file fetched on 2026-10-09 with a single `curl` request per page (raw HTML or raw file, converted to text locally; no summarising fetch tool). The Hub metadata (licence tags, revisions, gating) is in `outputs/corpora_census_2026-10-09.json`. Nothing was downloaded from any dataset repository; only the API, the dataset cards (`README.md`) and the licence pages were read.

**What we do with the data:** read the texts locally, tokenise them with pinned tokenizers, hash context tuples and compute detection statistics under many random keys. **What we publish:** statistics, figures and tables; code; manifests (URLs, revisions, byte sizes, SHA-256); never the texts. Attribution notices for every source go into the paper and the public repository's README. No corpus is redistributed, so the share-alike conditions (which attach to shared adapted material) are not triggered; the attribution conditions are met by citation and notice.
