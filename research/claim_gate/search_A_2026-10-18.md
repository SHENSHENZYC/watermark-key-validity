# Claim-gate literature screen A — theory, simulation and measurement claims (items a–d)

Date of search: 2026-10-18 (calls made 2026-10-19 00:25–00:43 UTC). Screener: Claude Code (Fable 5.1), literature-screening subagent.
Scope: any work, at any date, that already (a) derives an across-key variance/dispersion law for a watermark detector's false-positive rate or the per-key green mass / mean-score shift; (b) models the per-key false-positive rate with random-effects / mixed / two-way (key x text) variance decompositions or predicts its across-key SD from corpus statistics; (c) measures the per-key false-positive rate over many keys across languages, registers, tokenizers, context widths or lengths, or reports a per-key disparity; (d) frames per-key validity as training-conditional / conditional validity, or applies conformal or tolerance-region sample-size theory to per-key thresholds.
Raw outputs: `research/claim_gate/raw_A/` (143 files; every API response, search-page HTML, abstract-page HTML, run logs with UTC times, and parsed extracts). Nothing was downloaded as a PDF; nothing in the repository was changed other than this file and `raw_A/`.

Conventions. OBSERVED = read from a record or page. INFERENCE = the screener's reading. RECOMMENDATION = what the conductor might do with it. Quotations: at most one per item, under 15 words, taken only from the arXiv abstract page or the OpenAlex record (never from a search snippet). The known list of the task prompt (42 arXiv ids plus the textGrain report, SynthID-Text, the Genhatharan GitHub paper, the vLLM docs) is not re-reported; only version dates after 2026-10-13 would have been.

Note on the arXiv API (OBSERVED): phrase queries containing hyphens are tokenised on the hyphen, so `"key-to-key"` behaved like a search for "key ... key" (it returned three papers none of which uses the phrase) and `"per-key"` matched "per key". Nineteen queries returned zero entries on a first run and again on a second run 30 s later (the API's known first-call empty-feed artefact was therefore excluded); ten of these were cross-checked on the arXiv search page (a different engine), which returned the same zero or the same hits.
