# Data layout (Stage 4, frozen 2026-10-09; procedure v3 after R02 rounds 1 and 2)

All raw text stays local and git-ignored under `research/corpora/data/`; everything tracked is metadata, counts and hashes.

| What | Where | Tracked? |
|---|---|---|
| Terms of use (every source, quoted) | `research/corpora/TERMS_OF_USE_CHECK.md` | yes |
| Audit memo: sources, proceed rule P1–P8, holdout rule, implementation record, results, verdict | `research/corpora/CORPORA_AUDIT_v0.3.md` (v0.1 and v0.2 kept as superseded records) | yes |
| Access census (Hub metadata, viewer counts with partial flags) | `outputs/corpora_census_2026-10-09.json` (`tools/census_hub.py`) | yes |
| Freeze manifest: repo id, path, revision, UTC time, bytes, local SHA-256, Hub LFS SHA-256, status | `outputs/corpora_manifest_v0.1.json` (`tools/freeze_corpora.py`) | yes |
| Raw frozen files (Dolma gzipped JSON lines for the Common Pile; Parquet for Wikipedia) | `research/corpora/data/<news|stackexchange|gutenberg|wikipedia>/…` | **no** (git-ignored) |
| Per-unit metadata (source, language, file and position, canonical id, licence label and identity by a closed allow-list, allowed flag, token counts under both tokenizers on a capped prefix with censoring flag, normalised-text SHA-256, shingle kind and count); MinHash signatures; tokenizer file digests and conventions | `outputs/corpora_units_v0.3/units__<file>.parquet`, `signatures__<file>.npy`, `counts.json` (hard links of the v0.2 loader outputs; `tools/corpora_loader.py`; a file with a decompression or accounting failure is quarantined, `quarantine__*`) | no (local; `*.parquet` and `*.npy` are git-ignored; counts.json is tracked). `outputs/corpora_units_v0.1/` (estimate-based confirmation) and `outputs/corpora_units_v0.2/` (prefiltered candidates) are the superseded implementations, kept as the record |
| Clusters and partition (cluster id, size, representative flag, exposure hit, forced-open flag, open/holdout): the **finalised, versioned map** that the seal binds to, with its digest; `partition.parquet` is the provisional map of the last run | `outputs/corpora_units_v0.3/partition_v0.3.parquet` + `partition_v0.3.sha256` + `units_v0.3.sha256`, `partition_summary.json` (`tools/corpora_partition.py`: per-file acceptance, every distinct band-sharing pair of the prefix signatures as a candidate with no prefilter, **each confirmed by the exact Jaccard of full-text 5-gram shingle fingerprints**; `tools/corpora_build.py` runs the provisional count/expansion loop, stops on an integrity failure, and finalises once; an existing final version is refused before any write and there is no overwrite option) | summary and digests yes; parquet no |
| Exposure record (units whose text was seen before the partition; their clusters are forced open) | `outputs/exposure_records_v0.1.json`, `outputs/exposure_inspection_2026-10-09.json` | yes |
| Audit results (count flow, reconciliations, rules, cells, seal test) | `outputs/corpora_audit_v0.3.json` (`tools/audit_corpora.py`; v0.1 and v0.2 kept) | yes |
| Near-duplicate validation on planted copies under the production predicate (exact and estimated Jaccard, bands shared, linkage under three rules, same-source negatives, a 60-variant large-bucket case) and the metadata-only comparison of the decided rule with the pre-set rule | `outputs/dedup_validation_2026-10-09.md` (`tools/test_dedup.py`); `outputs/dedup_d4_additions_2026-10-09.json`; `outputs/dedup_settings_comparison_2026-10-09.json` (the round-1 comparison under the prefiltered procedure, kept as the record) | yes |
| **The seal**: the only sanctioned text access for scientific use | `tools/corpora_access.py`: `Access(units_dir, version).load_texts(canonical_ids, partition, final_lock=None, study=None, cells=None)` binds to the finalised map, its digest and the units-metadata digest, resolves every id against the map, and opens the held-out partition only for a lock registered in `outputs/corpora_seal_allowlist.json` (empty) that carries `final: true`, the study name, the manifest digest, the partition digest, the units digest and the cells `source/lang@L`; every requested unit must lie within those cells by its bound source, language and length eligibility; openings (with the digest of the requested ids) are appended to `outputs/holdout_openings.jsonl` (absent until the first opening). Fixture tests: `tools/test_seal.py` (17 cases). Preprocessing reads before finalisation (exact duplicate confirmation; the planted-copy fixture on exposed units) use `corpora_partition._preprocessing_text_reader`, which is not a scientific path | yes |
| Tokenizers (pinned, from the local Hugging Face cache) | Llama-3.2-1B `4e20de362430…` (128k), Qwen2.5-1.5B `8faed761d45a…` (152k) | cache, not in the repo |

Units: one news article; one Stack Exchange thread (question, answers, comments); one Project Gutenberg book, whose study window starts at token 1,000; one Wikipedia article. A unit is **eligible** for length L when its Llama-3.2 token count (censored at 12,000 characters, 24,000 for books) is ≥ L (books: ≥ 1,000 + L); the Qwen-eligible subset is reported beside it. Analysis units are cluster **representatives** with an allow-listed licence; non-representative duplicates are never scored.

Holdout (decision D3): a cluster is held out when `int(sha256(cluster_id)[:16], 16) % 5 == 0` and holds no exposure record; development keys are seeds 0–999, confirmatory keys 10,000–10,999, both from NumPy PCG64 streams keyed by the seed; the held-out partition opens only for a registered final lock, and every opening is logged.

Re-verification: recompute SHA-256 of each `local_path` in the manifest and compare with `sha256` and `hub_lfs_sha256` (data files; the READMEs have no LFS digest); recompute the digests of `partition_v0.3.parquet` and of the units files plus counts.json against `partition_v0.3.sha256` and `units_v0.3.sha256`; re-run `tools/audit_corpora.py outputs/corpora_units_v0.3 --version 0.3 --out outputs/corpora_audit_v0.3_recheck.json` and compare it with `outputs/corpora_audit_v0.3.json` (never overwrite the saved audit); run `tools/test_seal.py` and `tools/test_dedup.py outputs/corpora_units_v0.3`.
